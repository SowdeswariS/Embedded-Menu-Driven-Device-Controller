## Title of the Project
Embedded Menu Driven Device Controller

## Introduction:
This project is designed to control multiple electrical devices using a joystick-based menu
navigation system. An OLED display is used to show menu options, while relays and LEDs
are controlled through user selection. The project demonstrates embedded user interface
design, GPIO interfacing, and menu-based control systems.

## Problem Statement
Most simple embedded systems use direct switches for controlling devices, which becomes
difficult when the number of devices increases. A compact and user-friendly menu-driven
controller is needed to manage multiple devices efficiently using fewer input controls.

## Objectives 
To design a menu-driven embedded interface
To interface a joystick with a microcontroller
To display menus on an OLED display
To control multiple devices using relays and LEDs 
To learn embedded UI and GPIO programming

## Scope of the Project
The project controls multiple low-power devices using joystick navigation and menu
selection. It is suitable for educational and home automation demonstrations. The system
does not include wireless communication or mobile application control.

## Methodology / Working Principle
1. Joystick inputs are continuously monitored by the microcontroller.
2. OLED display shows menu options and device status.
3. User navigates through the menu using the joystick.
4. Selected device is turned ON/OFF using relays or LEDs.
5. System updates the display in real time.
